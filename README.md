# Oracle Delay Predictor - AI Tool (Streamlit App)

This app helps Oracle project managers and PMOs assess delivery risk using AI-based rules.

## Features:
- Upload Oracle project CSV file
- Auto risk tagging (High/Low) based on duration, phase, and dependencies
- Visual dashboard (Streamlit UI)

## Sample Data:
Located in `sample_data/complex_oracle_project.csv`

## Deployment:
Compatible with Streamlit Cloud.

## Requirements:
- Python 3.9+
- pandas
- streamlit
